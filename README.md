# DFT-visualizer
Python scripts for creating Gaussian inputs, extracting data, visualizing dipole moments, bond lengths, etc.

CAUTION: These scripts have been tested only for linearly fused polycyclic π-systems (e.g., acenes, phenacenes, DPND, xanthene, fluorene dyes). They are not recommended for branched or pericondensed systems such as coronene, pyrene, or similar architectures.

DipoleVisBL.py  - extracts data from .log files, project molecule onto 2D plane with dipole moments and/or bond lengths

xyz2BL.py       - extracts data from .xyz files, project molecule onto 2D plane with bond lengths
